構造化データにおける代表的な機械学習手法

構造化データとは？

  • データベースやExcelなどで扱われる、行と列からなる表形式のデータ
  • 年齢、年収、購入有無など各列（変数、特徴量）に明確な意味がある
  • 顧客データや購買履歴、Webサイトのアクセスログなど、企業で扱われるデータの多くがこれにあたる
  • 対して、画像、音声、テキスト、動画などは非構造化データ

以下は、構造化データを実務で扱う際によく使われる代表的な機械学習手法たち。なお、XGBoost/LightGBM/CatBoostはGBDTをベースにした手法。

GBDT: Gradient Boosting Decision Tree 勾配ブースティング決定木

  • 決定木を1本ずつ順番に追加し、前までのモデルがうまく予測できなかった部分を次の木で補正していくアンサンブル学習の手法。
  • 複数の決定木を組み合わせることで、複雑な非線形関係や特徴量同士の相互作用を捉えやすい。

ロジスティック回帰

シンプルで軽量なモデルで、分類問題のベースラインとしても重要な手法。Logistic Regression

  • 仕組み：特徴量の線形結合をシグモイド関数に通して、イベント発生確率をモデル化する。一般化線形モデル（GLM Generalized Linear Model）の一種。
  • 長所：各特徴量の影響を回帰係数やオッズ比として解釈しやすい。計算も軽く、ベースラインモデルとして使いやすい。
  • 短所：特徴量間の複雑な依存関係や非線形な関係を捉えるのが苦手。必要に応じて交互作用項や変換を手動で追加する必要がある。
  • 注意点：特徴量のスケールや多重共線性の影響を受けることがある。

Random Forest

複数の決定木を組み合わせるアンサンブル学習。比較的扱いやすく、非線形な関係も捉えられる。

  • 仕組み：複数の決定木を独立に構築し、回帰では予測値の平均、分類では多数決によって最終的な予測をおこなう。代表的なバギング（Bagging）の手法。
  • 長所：木を独立して学習できるため並列化しやすく、比較的安定した予測性能を得やすい。初期設定でも一定の性能が期待できる。
  • 短所：木の本数や深さを増やすと、モデルサイズや推論時間が大きくなりやすい。GBDT系と比べて予測精度で劣る場合もある。
  • 特徴：複数の木を組み合わせて個々の木の予測のばらつきを抑えることで、過学習を抑えやすくしている。

XGBoost

決定木を順番に追加していくGBDT（勾配ブースティング決定木）の代表的な実装。高い予測性能と汎用性を持つ。eXtreme Gradient Boosting

  • 仕組み：前の決定木の予測誤差をもとに次の木を追加していくGBDTをベースに、Level-wise方式による木の成長、正則化、計算の効率化など、さまざまな改良を加えている。
  • 長所：非線形な関係や特徴量同士の相互作用を捉えやすく、幅広いデータで高い予測性能を発揮しやすい。汎用性も高い。
  • 短所：LightGBMと比較すると、学習に時間やメモリを多く必要とする場合がある。
  • 特徴：L1/L2正則化などを組み込んでおり、過学習を抑えながら高い予測性能を狙える。

Level-wise: 木を横に広げていく育て方。同じ深さにあるノードを優先して分割し、木を階層ごとに成長させていく方式。

LightGBM

高速な学習と省メモリ化を重視したGBDTの実装。大規模な表形式データを扱いやすい。

  • 仕組み：GBDTをベースに、Leaf-wise方式による木の成長やGOSS、EFBなどの工夫を取り入れ、学習を効率化している。
  • 長所：学習が高速でメモリ消費も抑えやすく、大規模なデータや高次元のデータを扱いやすい。
  • 短所：Leaf-wise方式によって一部の枝が深くなりやすく、データ量が少ない場合などには過学習に注意が必要。
  • 特徴：速度と予測性能のバランスに優れ、表形式データの機械学習で広く利用されている。

Leaf-wise: 木を縦に伸ばしていく育て方。分割によって損失を最も大きく減らせそうな葉を選び、そこを優先して深くしていく方式。

GOSS: Gradient-based One-Side Sampling 勾配の大きいデータを優先的に残し、勾配の小さいデータを一部サンプリングすることで、分割探索に使うデータ量を減らす。

EFB: Exclusive Feature Bundling 同時に値を持つことが少ない特徴量をひとつにまとめ、特徴量の数を減らすことで計算を効率化する。

CatBoost

カテゴリ変数を含む表形式データを扱いやすくすることに重点を置いたGBDTの実装。Categorical Boosting

  • 仕組み：GBDTをベースに、カテゴリ変数を効率的に扱うための独自の仕組みを取り入れている。
  • 長所：カテゴリ変数をone-hot encodingだけに頼らず扱うことができ、カテゴリ数の多いデータでも利用しやすい。
  • 短所：データや問題によっては、XGBoostやLightGBMのほうが適している場合がある。
  • 特徴：カテゴリ特徴量の統計量を計算する際にtarget leakageを抑える仕組みなどを備えている。
